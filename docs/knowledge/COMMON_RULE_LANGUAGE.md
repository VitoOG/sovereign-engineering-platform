# Common Rule Language for Humans, Robots, and AI

Artifact Type: SPEC
Maturity Status: CONCEPT

Model:

System -> Rule -> Authority -> Human/Robot/AI -> Interface/API -> Execution -> Verification -> Evidence

Rule schema:

- ID
- NAME
- PURPOSE
- SCOPE
- PRECONDITIONS
- CONDITIONS
- ACTION
- CONSTRAINTS
- SAFETY
- AUTHORITY
- VERIFICATION
- ROLLBACK
- PROVENANCE

Thesis:

Humans, robots, and AI can share the same system knowledge and rules while retaining different authority levels.
