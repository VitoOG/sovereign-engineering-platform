# Knowledge Architecture

Artifact Type: SPEC
Maturity Status: CONCEPT

Knowledge objects:

- Documents
- Facts
- Concepts
- Procedures
- Specifications
- Decisions
- Observations
- Hypotheses
- Experiments
- Evidence
- Provenance

Core pipeline:

Data -> Information -> Knowledge -> Decision -> Action -> Evidence

Control distinction:

Knowledge != Rule
Rule != Command
Command != Execution
Execution -> Evidence
