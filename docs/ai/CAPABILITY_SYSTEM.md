# Capability System Cheat Sheet

Artifact Type: SPEC
Maturity Status: CONCEPT

Distinctions:

- Capability: atomic operation contract
- Workflow: ordered composition of capabilities
- Macro: deterministic local automation sequence
- Agent: reasoning and orchestration component
- Rule: constraint and authority boundary
- Evidence: validation artifact
- Learning: model or process update from evidence
- Evolution: validated system-level improvement

Primitive capabilities:

- file.search
- file.read
- file.write
- file.copy
- file.move
- file.rename
- file.archive
- file.convert
- text.rewrite
- markdown.normalize
- pdf.extract
- image.process
- diagnostics.run
- backup.create
- git.commit
- macro.execute

Missing capability protocol:

Discover -> Design -> Implement -> Validate -> Register -> Reuse
